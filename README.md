# xAI Warp Drive - Ultimate Control

一个交互式的星空粒子动画效果，模拟超光速飞行时的视觉效果。

## 功能特性

- 🚀 **动态速度控制** - 可调节飞行速度（0-20倍速）
- 🎨 **多彩粒子系统** - 支持8种颜色组合选择
- ✨ **可调拖尾效果** - 自定义粒子拖尾长度
- 📏 **颗粒大小控制** - 实时调整粒子大小
- 🎯 **密度调节** - 控制粒子数量（500-3000）
- 🖱️ **鼠标交互** - 鼠标移动影响粒子运动方向

## 使用方法

直接用浏览器打开 `index.html` 文件即可运行。

## 控制面板

- **SPEED (速度)**: 控制粒子移动速度
- **TRAIL (拖尾长度)**: 调整粒子拖尾效果
- **SIZE (颗粒大小)**: 控制粒子显示大小
- **DENSITY (密度)**: 调整粒子数量
- **COLORS (颜色组合)**: 选择激活的颜色（可多选）

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- Canvas API 2D 渲染
- 无依赖，可直接运行
